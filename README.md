# Sümer Elektrik — Kurumsal Hizmet ve Arıza Talep Web Platformu

[![Live Site](https://img.shields.io/badge/Canlı_Site-sumerelektrik.netlify.app-00C7B7?style=for-the-badge&logo=netlify&logoColor=white)](https://sumerelektrik.netlify.app)

Mersin / Erdemli bölgesinde elektrik teknik servis ve taahhüt hizmeti sunan müşteri için React ve Tailwind CSS ile geliştirilmiş kurumsal web platformudur *(2026 • Tamamlandı)*.

## Yapılan Çalışmalar

- **Bileşen Tabanlı Arayüz:** React ve Tailwind CSS ile mobil öncelikli, hızlı açılan hizmet sayfaları ve yapılandırılmış arıza bildirim / talep formları.
- **Yerel Arama (Local SEO) Optimizasyonu:** Bölgesel hizmet anahtar kelimeleri, temiz semantik HTML ve Netlify üzerinden canlı yayın.
